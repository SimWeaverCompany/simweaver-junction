# Contributing to Junction

Thank you for your interest in contributing to SimWeaver Junction.

## Before submitting a contribution

1. Check existing issues and pull requests to avoid duplicated work.
2. For substantial changes, open an issue or discussion first so the proposed approach can be discussed.
3. Make changes that are focused and include tests or documentation where appropriate.
4. Ensure you have the right to submit all code and other materials in your contribution.

## Contributor License Agreement (CLA)

Before the project accepts a contribution, contributors must accept the project's Contributor License Agreement (`CLA.md`) through the process specified by the maintainers.

The CLA is intended to let contributors retain ownership of their contributions while granting Simweaver AB the rights described in the agreement, including the ability to distribute contributions under the project's open source license and, where permitted by the CLA, under other license terms.

Do not submit third-party code unless its origin and license are clear and compatible with the proposed contribution. Disclose third-party materials in your pull request.

## Pull requests

- Explain the problem and the proposed solution.
- Keep pull requests as small and focused as practical.
- Include relevant tests and update documentation when needed.
- Be responsive to review feedback.
- Do not include credentials, secrets, customer data, or confidential information.
