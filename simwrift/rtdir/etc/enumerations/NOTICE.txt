What SimWeaver does with it: the Rift object view names entity types with it (for example
1.1.205.2.1.5.0 -> "SWE CV9040A, Armored Fighting Vehicle"). It is read once when the server
starts. To use a newer release, replace the file with SISO's (same name), or point
enumerations.siso.file in etc/server.root.settings at it, and restart. Without the file, entity
types are shown as numbers only.
