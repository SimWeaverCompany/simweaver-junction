This server is not part of a J2J network: etc/j2j/network.settings lists no members. The J2J button is hidden in the top bar of the other pages until J2J is configured.

  1. List every member of the network in etc/j2j/network.settings: the same file on every server.
  2. Put the network key in etc/j2j/network.key on every server (New key text below makes one).
  3. Set this server's id: j2j.node.id= in etc/server.root.settings.
  4. Reload the member list here, or restart the server.
network.id=exercise-net
network.name=Exercise network North
member.sto-1.name=Stockholm lab
member.sto-1.addresses=10.10.0.5:8844
member.got-2.name=Gothenburg
member.got-2.addresses=10.20.0.7
